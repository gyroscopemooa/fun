# Image checkout price decision — 2026-11-13

User authorization: replace the KRW 100,000 placeholder with an API-cost-based image-product price and simplify the payment popup. Display recommendation selected: KRW 9,900 for one completed image result, not for one upstream request. The server allowlist supplies the same review amount; browser-supplied prices are ignored. Other products are not priced from this image estimate.

Repository default is `gpt-image-2`, size 1024x1536. The normal photo transformation uses two medium-quality edits; stage two can retry once. The body mode first tries a high-quality generation and can fall back to the edit pipeline. Thus one sold result can involve several billed upstream operations, not one medium image. Environment overrides and real deployed provider usage have not been verified.

Official sources checked: https://developers.openai.com/api/docs/pricing and https://developers.openai.com/api/docs/guides/image-generation . Costs include input text, input images and generated output; input size and retries matter. The model page https://developers.openai.com/api/docs/models/gpt-image-2 currently marks the model deprecated. Do not silently switch model or claim its account availability was tested. No API call was made for this estimate.

Planning assumption, not measured cost or current exchange-rate assertion: budget KRW 500 per completed sale, using KRW 1,500/USD as a conservative planning conversion and allowing for input tokens, multiple calls, retries and variable overhead. Margin means (net revenue minus costs) / net revenue, not markup. On API budget alone, 50% requires KRW 1,000 and 90% requires KRW 5,000; these exclude payment fees and taxes. Recommended consumer price candidates are KRW 1,490 and KRW 9,900 respectively to provide more room. For illustration only, assuming VAT-inclusive prices with 10% VAT and a 3.5% gross-price payment fee, KRW 9,900 leaves approximately 90.6% contribution margin after a KRW 500 cost. These tax/fee values are assumptions, not verified merchant rates or accounting advice. Actual billed usage, tax treatment, settlement fees, failure rates and hosting must be measured before claiming a realized margin. KRW 9,900 is a proposed launch price; no actual approval is enabled.
