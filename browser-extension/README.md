# 매니툴 브라우저 확장 · 개발 미리보기 0.1.0

Chrome / Edge Manifest V3, Chrome 116 이상. **스토어 미등록, 운영 미배포, 실제 브라우저 검증 전**입니다. 별도 사용자 쿠키 기능 브랜치와 분리하여 `main d2ab196`에서 시작했습니다.

## 구현한 기능
- 명시적인 버튼 또는 `Alt+Shift+S` → 영역 드래그 캡처 → 로컬 검토 → PNG 저장.
- 글자를 선택하고 우클릭 또는 확장 팝업 → 검토·편집·복사 → Google 검색(별도 전송 확인).
- 캡처 PNG를 로컬에서 WebP/JPG/PNG로 변환, 품질 조정, 비율을 유지한 축소. 손실 압축이 항상 용량을 줄인다고 보장하지 않습니다.
- 선택 내용과 명시적 동의를 확인한 다음 매니툴 OCR·한↔영 번역·현재 영상 주소 입력란으로 전달. **자동 실행/결제는 하지 않습니다.**
- 선택 글의 `/selection-workbench/` 연결 버튼. 해당 별도 페이지가 배포되어야 동작합니다.
- 유료 AI 요약·설명은 준비 중 UI입니다. 서버 호출·결제·크레딧 차감은 없습니다.

- 팝업에서 현재 페이지 드래그 메뉴를 명시적으로 켜면 글 선택 시 작은 검토 버튼이 표시됩니다. 입력란은 제외하고 클릭 전 외부 전송하지 않습니다. 페이지 이동 또는 10분 만료 후 다시 켜야 합니다. × 버튼으로 종료합니다.
- 이미지 우클릭 → 로컬 PNG 읽기·검토·변환. 원본 이미지가 Canvas 읽기를 제한하거나 너무 크면 영역 캡처를 안내합니다. 로그인 쿠키 전달이나 교차 출처 우회는 하지 않습니다.

## 웹 도구와 연결
`src/lib/extension/import.ts`와 문서/영상 컴포넌트 변경을 함께 배포해야 입력 전달이 동작합니다. 기존 운영 사이트에는 이 연결 코드가 없으므로 타임아웃 후 수동 복사/저장을 안내합니다. 캡처·로컬 이미지 변환·복사·검색은 사이트 배포와 별개입니다.

전달은 사용자가 허용한 `https://manytool.net/*`만 대상으로 합니다. 준비 상태 확인은 내용 없이 수행하며, 그 문서 ID에 고정하여 한 번 전달합니다. URL·쿼리·페이지 기록에는 원문/이미지를 싣지 않습니다. 임의 외부 목적지, 자동 유료 호출, 전체 방문 기록은 없습니다. 사이트의 다른 스크립트도 전달된 내용을 볼 수 있으므로 동의 화면에 명시합니다. DOM 이벤트는 인증 수단이 아니며 로그인/결제 권한으로 사용하면 안 됩니다.

## 설치/테스트
1. `node scripts/package-browser-extension.mjs`로 `tmp/extension/manytool-extension-0.1.0.zip` 생성.
2. PC에서 ZIP을 압축 해제.
3. `chrome://extensions` 또는 `edge://extensions`의 개발자 모드에서 **압축해제된 확장 프로그램 로드**로 폴더 선택.
4. 일반 HTTPS 페이지를 열고 확장 버튼 고정 후 실행. 브라우저 설정/스토어/일부 특수 페이지는 실행 불가.
5. OCR·번역은 별도 웹 도구에서 모델 파일 다운로드가 필요할 수 있습니다. 로그인/스토리 다운로드와 상점 배포 승인을 의미하지 않습니다.

## 권한·보관
- 기본: `activeTab`, `scripting`, `contextMenus`, `storage`, `alarms`.
- 선택: `https://manytool.net/*`만. 모든 사이트 권한·cookies·history·debugger·webRequest 없음.
- 원본 전체 화면은 캡처 함수 메모리에서만 사용하고 선택 영역만 검토 저장소로 넘깁니다.
- 한 번에 대기 중 자료 1개, PNG 데이터 URL 최대 4MiB. 읽으면 세션 저장소에서 즉시 제거. 대기 중 자료는 10분 후 다음 1분 정리 주기에 제거(절전 시 지연 가능).
- 새 탭/문서 이동, 탭 전환, 창 포커스 변경 시 진행 중 캡처는 폐기합니다. 전달 대기는 ‘내용 지우기’로 취소할 수 있습니다. 이미 전달된 내용은 대상 도구에서 지워야 합니다.

## 검증과 남은 일
- `node --test browser-extension/tests/*.test.js`: URL·크기·권한·취소·문서 고정·캡처 도중 전환·데이터 입력 테스트.
- `node --check browser-extension/*.js` (각 파일) 및 변경 TS/React 타입 검사.
- `ASTRO_TELEMETRY_DISABLED=1 npm run build`: 전체 웹 빌드.
- 실제 Chromium 시작이 실행 환경의 `socket() failed: Operation not permitted`로 막혔습니다. 권한 프롬프트, 드래그 캡처, 교차 실행 컨텍스트 이벤트, 이미지 실제 저장, 클립보드, 반복/취소 및 뒤로가기 UI는 **실브라우저 미검증**입니다.
- 게시 전 Chrome/Edge 수동 검증, 최종 아이콘·스토어 이미지·개인정보처리방침, 스토어 정책 검토 필요.
- 로그인 영상/스토리, 유료 AI/크레딧 결제는 미구현입니다. 새 드래그 메뉴와 이미지 우클릭은 코드·자동 테스트만 완료, 실브라우저 검증은 남아 있습니다.
