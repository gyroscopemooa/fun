# 매니툴 간편결제 I009 설정 확인 요청 — 발송 전 초안

수신 예정: NICE 담당자 pghelp@nicevan.co.kr (기존 문의 스레드 회신용). 이 문서는 발송하거나 심사를 제출한 기록이 아닙니다.

제목: manytool.net 단건 MID 000000002m 간편결제 인증창 I009 설정 확인 요청

안녕하세요. manytool.net 단건결제 MID 000000002m의 간편결제 인증창 연결 확인을 요청드립니다.

정식 상품 https://manytool.net/ai-image-generator/ 에서 이미지 선택 후 실행 버튼 → 약관 확인 → 결제수단 선택 경로로 진입할 수 있습니다. 현재 이미지 상품 예정가는 9,900원이며, 연결 확인 중에는 실제 승인·청구·상품 지급을 차단하고 있습니다.

NICE 공식 인증결제 v3 직접 호출 옵션으로 아래와 같이 요청했으나, 실제 브라우저에서 다음 오류가 확인됐습니다.

- 네이버페이: PayMethod=CARD / DirectShowOpt=CARD / DirectEasyPay=E020 / EasyPayMethod=E020=CARD → I009: 결제수단이 유효하지 않습니다.
- 토스페이: PayMethod=CARD / DirectShowOpt=CARD / DirectEasyPay=E025 / EasyPayMethod=E025=CARD → I009: 결제수단이 유효하지 않습니다.
- 카카오페이: PayMethod=CARD / DirectShowOpt=CARD / DirectEasyPay=E016 → I009: 카카오페이가 설정되지 않은 MID입니다.

해당 단건 MID에 각 간편결제가 등록·사용 설정되어 있는지 확인 부탁드립니다. 미등록 상태라면 카드사 심사 전에 인증창 연동을 확인할 수 있도록 설정 가능한지, 또는 사전 신청·별도 계약·심사가 필요한지 안내 부탁드립니다. 심사 전에는 별도의 테스트 MID가 필요한 경우에도 무과금 테스트 자격과 절차를 안내 부탁드립니다.

삼성페이·Apple Pay·PAYCO도 단건 MID 기준으로 필요한 신청·설정과 기기별 테스트 조건을 구분해 안내 부탁드립니다. 이 세 수단의 연결 성공 여부는 아직 확인되지 않았습니다. 포인트 충전 MID 000000004m에 간편결제를 요청하는 내용은 아닙니다.

다른 서비스에서 간편결제가 연결되는 사례를 매니툴의 승인으로 간주하지 않고, 매니툴 MID의 설정을 별도로 확인하고자 합니다. 실제 금전 결제나 승인·취소 시험은 진행하지 않았습니다. 키·비밀번호·서명·인증 토큰은 첨부하지 않습니다.

감사합니다.

## 증거와 한계

사용자가 제공한 실제 브라우저 스크린샷 3장에 위 I009 메시지가 표시돼 있습니다. 이전 gateway 초기화 HTTP 200/0000은 이후 페이 인증창 성공을 증명하지 않습니다. 현재 NICE 관리자 확인은 웨일 제어 도구의 창 소유자 인식 오류로 막혀 있습니다. 간편결제 등록·심사·활성화가 완료됐다고 보고하지 않습니다.
