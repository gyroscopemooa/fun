업로드 제한이 **KB·MB**로 표시된다면 가로·세로 픽셀뿐 아니라 **저장된 파일의 용량**을 확인하세요. 표시된 KB가 제한과 같더라도 반올림과 단위 계산 기준 때문에 실제 제한을 넘을 수 있습니다. 매니툴에서는 이미지 용량 줄이기 도구로 JPG 파일을 만든 뒤 결과 용량을 비교할 수 있습니다. 매니툴 운영팀이 현재 구현을 확인해 작성한 안내입니다.

## 시작 전에 제출 조건을 확인하세요

업로드할 곳에서 요구하는 최대 용량, 허용 파일 형식, 최소 가로·세로 픽셀을 먼저 적어 두세요. 용량만 맞추려고 사진을 너무 작게 줄이면 해상도 조건을 충족하지 못할 수 있습니다. 특정 사이트의 기준은 해당 업로드 화면 안내를 우선합니다.

매니툴 **이미지 용량 줄이기**는 원본의 가로·세로 픽셀 수를 유지한 채 JPG로 다시 저장합니다. **이미지 사이즈 변경기**는 가로·세로 픽셀을 바꾸고 PNG로 저장합니다. 따라서 픽셀을 줄인 PNG의 파일 용량이 원래 JPG보다 클 수도 있습니다.

## 압축하고 확인하는 순서

1. 원본 사진을 별도로 보관합니다.
2. [이미지 용량 줄이기](/image-compressor)에서 사진을 선택합니다.
3. 압축 품질을 설정하고 **압축하기**를 누릅니다.
4. 표시된 원본·압축 용량을 비교합니다. 더 작은 파일이 만들어진 경우 다운로드합니다.
5. 저장된 JPG를 열어 글씨나 얼굴이 필요한 만큼 선명한지 확인한 후 업로드합니다.

품질을 낮추면 손실이 커질 수 있습니다. 특정 용량 이하를 자동 보장하는 기능은 없으므로 업로드할 사이트의 제한과 결과를 직접 비교해야 합니다. 품질을 바꾼 뒤에는 **압축하기**를 다시 눌러 새 결과를 생성하세요. 슬라이더만 움직여서는 이미 만들어진 다운로드 파일이 갱신되지 않습니다.

## 표시 용량은 제한과 같은데 업로드가 거절된다면

현재 압축 도구는 파일의 바이트 수를 **1024로 나눈 뒤 소수 첫째 자리까지 반올림**하고 `KB`로 표시합니다. 표시 숫자가 제출처의 제한과 같다는 것만으로 통과를 보장하지는 않습니다.

예를 들어 102,401바이트인 파일도 이 도구에서는 `100.0KB`로 표시됩니다. 제출처가 최대 102,400바이트를 허용한다면 1바이트 초과입니다. 제출처가 100KB를 100,000바이트로 계산한다면 차이는 더 커집니다. 이는 계산 예시이며 특정 제출처의 기준을 뜻하지 않습니다.

1. 다운로드한 JPG의 파일 정보에서 가능하면 **바이트 단위의 크기**를 확인합니다. Windows 파일 속성에서는 저장 공간을 뜻하는 **디스크 할당 크기**가 아니라 **크기** 항목을 봅니다.
2. 제출처가 바이트 기준을 안내한다면 그 값과 비교합니다. KB·MB만 안내한다면 표시 한계에 딱 맞추기보다 여유 있게 줄여 다시 확인하세요.
3. 도구에 선택한 원본의 품질을 조금 낮추고 **압축하기**를 다시 누른 뒤 새 파일을 받습니다. 다운로드 폴더에 같은 이름의 파일이 여러 개라면 방금 저장한 파일을 확인하고 업로드 첨부도 교체합니다.
4. 용량을 충족해도 거절된다면 허용 확장자와 최소 픽셀, 가로·세로 비율을 확인합니다. 이 도구에는 제출처별 조건을 자동 검사하는 기능이 없습니다.

용량을 더 줄이자 글씨가 흐려진다면 아래의 픽셀 조정 순서를 검토하세요. 이미 최소 해상도라면 제출 조건이나 대체 제출 방법을 확인해야 합니다.

## 압축만으로 해결되지 않는 경우

이미 압축된 사진은 다시 저장해도 용량이 충분히 줄지 않거나 커질 수 있습니다. 품질을 낮추니 글씨부터 흐려진다면 무작정 더 낮추기보다 아래 순서로 확인하세요.

1. 원본 사본을 준비하고 업로드에 필요한 최소 픽셀 크기를 확인합니다.
2. 원본이 필요한 크기보다 클 때만 [사진 비율을 유지하며 가로 크기 바꾸는 방법](/community/image-resize-ratio/)에 따라 줄입니다. 비율 유지를 다시 켰다면 가로 값을 다시 입력하고 세로가 계산된 뒤 저장하세요.
3. 내려받은 PNG를 [이미지 용량 줄이기](/image-compressor)에 **새로 선택**합니다. 이전에 선택한 원본 사진이 자동으로 교체되지는 않습니다.
4. 품질을 설정하고 **압축하기**를 다시 누릅니다.
5. 새로 받은 JPG의 용량, 가로·세로 크기, 글씨 선명도를 확인한 뒤 업로드합니다.

제출에 필요한 최소 크기에 이미 맞춰진 사진이라면 픽셀을 더 줄이지 마세요. 허용 형식이나 제출 조건을 다시 확인하고, 조건을 동시에 만족시키기 어렵다면 제출처의 대체 업로드 방법을 확인하세요.

현재 압축 도구의 출력은 JPG입니다. **투명 배경을 보존해야 하는 이미지에는 적합하지 않습니다.** 브라우저에서 읽지 못하는 형식은 JPG 또는 PNG 원본을 준비해야 합니다. 파일이 너무 크면 기기의 메모리 한계로 처리가 어려울 수 있습니다.

## 업로드 조건도 함께 확인하세요

용량 외에 허용 확장자, 최소 가로·세로 크기, 사진 비율 조건이 있을 수 있습니다. 압축 결과가 작아졌더라도 해당 사이트의 조건을 모두 충족하는지 확인하세요.

직접 적용하려면 [사진 용량 줄이기](/image-compressor)에서 사본을 선택하세요. 픽셀 조정이 먼저 필요하다면 [가로·세로 크기 조절하기](/image-resizer)로 시작할 수 있습니다.
