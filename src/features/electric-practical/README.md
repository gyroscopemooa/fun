# 전기기능사 회로 시뮬레이터

공개 1번 시퀀스에 기반한 3상 220V RMS 학습 예제와 자체 제작한 24V 자기유지 과제를 제공한다. 공인 채점기가 아니다. 공개 1번의 기준·실행 증거·모델 한계는 `docs/electric-practical/public-one-verification.md`를 확인한다.
엔진은 React·DOM·네트워크·실시간 시계에 의존하지 않는다. 문서 JSON의 단자 연결이 유일한 전기적 입력이다.

## 실행

Node 22.18 이상 또는 Node 24 권장. 기존 ManyTool의 npm/React/Astro를 사용한다.

```sh
npm install
npm run check:electric
node scripts/electric-demo.ts
node scripts/electric-demo.ts --public1
npm run dev -- --host 127.0.0.1 --port 4337
```

로컬 페이지: http://127.0.0.1:4337/tools/electric-practical

```sh
npx playwright install chromium
npm run e2e:electric
npm run build
```

설치된 Edge로 검사하려면 PowerShell에서 `$env:PLAYWRIGHT_CHANNEL='msedge'` 설정 후 `npm run e2e:electric`을 실행한다.
최종 빌드 검증은 `npm run build -- --outDir .electric-preview` 후 `$env:ELECTRIC_PREVIEW='1'`을 설정하면 개발 서버 대신 프로덕션 미리보기 서버를 사용한다.
E2E는 없으면 4337 포트 개발 서버를 시작하며, 로컬 ManyTool 요청만 허용한다. 외부 광고·분석 요청은 테스트에서 차단한다.
lint와 typecheck는 이 기능 및 테스트/설정 파일을 대상으로 한다. 기존 프로젝트 전체에는 이 작업 이전부터 전역 lint/typecheck 명령이 없었다.

## 구조와 분리 경계

- `public-one`: 공식 기기 핀 배열, 3상 RMS 노드 계산, 타이머/플리커/FLS/EOCR 상태, 완성 배선 및 22개 시나리오. 기존 24V 엔진과 분리한다.

- `model`: 타입, 유효성 검증, 과제 부품/예제. 모든 부품 단자는 여러 전선 연결을 허용한다.
- `engine/compile.ts`: 도선과 닫힌 접점만 등가 노드로 묶는다. 화면 좌표나 선 교차를 읽지 않는다.
- `engine/conductivity.ts`: 코일/램프 저항을 남긴 노드 전압법. 떠 있는 네트워크는 전위 미정(null)으로 반환한다.
- `engine/simulate.ts`: 코일 → 접점 → 회로 계산의 고정점 반복. 동일 상태 재방문 또는 32회 제한에서 발진 실패. 전원 차단 시 코일 기억을 지운다.
- `grading`: 사용자 회로의 독립된 9단계 입력 시퀀스, 안전 금지조건, 지정 부품/단자 사용을 각각 검사한다.
- `editor`: SVG 단자/선/부품 조작. 편집 기록은 50회, 배선 도형은 계산에 영향이 없다.
- `screens`: 상태·조작·로그·검수 UI. 외부 API를 호출하지 않는다.
- `storage`: schemaVersion 1 JSON. 런타임 상태는 저장하지 않는다. 파일 500KB, 부품 80개, 전선 240개 제한.
- `tests/fixtures`: 정상/오배선/동등회로 전체 JSON 27개. 테스트에서 fixture를 다시 생성하지 않는다.

`SimulatorPage`를 React 앱에 가져오면 동일 UI를 재사용할 수 있다. ManyTool 의존성은 Astro 라우트의 Layout/Header/Footer/광고 래퍼에만 있다.

## 기본 24V 과제의 물리 모델 범위

단일 24V 가상 DC 전원, 이상 도선/접점, 코일 240Ω, 램프 480Ω 기본값이다.
코일은 이 과제에서 **극성이 있는 DC 부하**로 정의한다. A1은 양극, A2는 리턴이다. 램프는 무극성이다.
동작 문턱은 정격의 80%(19.2V)이며, 실제 제품의 흡입/탈락·히스테리시스 사양을 주장하지 않는다.
저항은 JSON에서 1Ω~1MΩ, 퓨즈 정격은 0.001~100A 범위로 설정할 수 있다.

단락은 **부하를 제외한 도선/닫힌 접점 그래프의 L–N 연결**이다. 정상 부하 연결을 단락으로 분류하지 않는다.
퓨즈는 연결 그래프의 브리지인 경우 KCL로 해당 퓨즈 전류를 계산한다. 다른 도선으로 우회한 퓨즈는 PROTECTION_BYPASS로 보고하며 전류 분배를 추측하지 않는다.
단락이나 퓨즈 과전류 시 가상 전원 전체가 보호 차단되고 오류가 래치된다. 이는 교육용 전원 인터록이며 실제 분기별 선택차단 모델이 아니다. 초기화로 복귀한다.
같은 단자 중복전선은 경고, 부하 양단 같은 노드는 MISWIRE, 미연결 단자는 OPEN, 전위 기준 없는 부하는 FLOATING이다.
정상적으로 열린 STOP/START 접점을 단선 오류로 판정하지 않는다. 동작을 막는 더 복잡한 오배선은 검수의 재현 단계/관련 단자로 안내한다.

초록선은 실제 비영 전류 부하에 대해 계산한 **대표 전원·리턴 경로**이다. 병렬 이상 도선의 전류 분배나 실제 전류 애니메이션을 표시하지 않는다.
전원이 꺼졌거나 단락/발진으로 실패한 경우 통전 하이라이트를 만들지 않는다.

지원하지 않음: AC 파형, 자기장/인덕턴스, 접점 바운스, 아크, 전선굵기, 접지, 절연저항, 누전, 열, 실제 고장 발생시간, 실제 퓨즈 I²t 곡선.
타이머/인터록/복수 릴레이 과제는 P1, 계정·클라우드 저장·결제·제한시간은 P2이다.
정적 일반 회로 표현이 가능하더라도 이번 합격 검증 범위는 단일 자기유지 과제다.

## 학습 과제와 검수

PS1 → F1 → STOP NC → (START NO ∥ MC1_NO) → MC1·PL1 병렬 → N.
J1 분기 대신 동일 단자에서 분기해도 된다. 임의 좌표, 전선 방향, 추가 분기점으로 구현한 동등 회로를 허용한다.
과제 지정 ID/종류는 PS1(SUPPLY), F1(FUSE), START(PUSH_NO), STOP(PUSH_NC), MC1(COIL), MC1_NO(AUX_NO), PL1(LAMP)이다.
보조접점은 MC1에 연동하고 지정 부품의 단자는 모두 사용한다. F1 분리 시험에서 부하가 켜지면 보호 우회로 불합격이다.
STOP 또는 F1을 열었을 때 부하 입력에 L이 남는 리턴 차단 결선도 별도 규칙으로 불합격 처리한다. 이 판단 역시 단자 그래프에서 계산한다.

검수 순서: 초기 정지 → START 누름 → 해제/유지 → STOP 누름 → STOP 해제 → 재시작 → 전원 차단 → 전원 복구 → START+STOP 동시 누름.
각 단계에 코일/램프 기대 상태, 실제 결과, 오류 코드, 관련 부품/단자, 수정 설명이 표시된다.
오류 카드를 선택하면 작업판의 관련 부품/배선이 강조된다. 채점은 예제 배선 목록이나 좌표를 비교하지 않는다.

## 저장과 개인정보

명시적인 로컬 저장만 사용하며 키는 `manytool:electric-practical:v1`이다. 기존 서비스 저장 키를 변경/삭제하지 않는다.
새로고침 후 로컬 불러오기를 눌러 복원한다. 자동 저장은 하지 않는다.
JSON 가져오기는 스키마/단자/수치/용량을 검증하고 실패 시 현재 작업을 유지한다. 오배선·잘못된 접점 연동은 수정을 위해 불러올 수 있다.
가져온 문자열은 React 텍스트로만 출력하고 HTML로 삽입하지 않는다. 이 기능에서 계정/결제/서버 저장/외부 로그 전송을 추가하지 않았다.
상위 ManyTool의 기존 분석·광고 정책은 그대로 적용된다.

## 검증 재현

`npm run test:electric`: fixture 27개, 100회 반복 결정성, 정전/빠른 입력, 직렬 전압, 실제 부하 변경/과전류, 저장 복원, 편집 기록 등을 검사한다.
`npm run e2e:electric`: 빈 작업판 마우스 결선, START/STOP, 결선 수리, 단락, Undo/Redo, 로컬/파일 저장, 키보드 편집, 모바일 읽기, ManyTool 진입/복귀 및 기존 퍼스널컬러 페이지 회귀를 검사한다.
실행 증거는 저장소 `docs/electric-practical/evidence`에 있다. 최종 검증 결과와 한계는 `docs/electric-practical/verification.md` 참조.

실물 전기제어 전문가가 확인할 사항: 코일 극성·흡입/탈락 조건·보호기기 사양의 제품별 차이, 실제 실기 규정과의 대응, 접지/절연/배선 안전.
공식 도면 PDF/이미지를 재배포하지 않는다. 공개 1번 예제는 큐넷의 2025-08-04 수정본을 대조해 작성한 독립적인 단자 결선 모델이다. TB5/TB6 세부 극 배정은 이 도구의 결선표를 따른다.
