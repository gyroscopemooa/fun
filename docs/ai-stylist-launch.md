# AI 코디 · NICE 연결 확인 단계

2026-11-15 사용자 요청: 반짝이 아이콘 교체, 토스 느낌의 파란 버튼·큰 글자·여백 중심 화면, 다른 AI 상품과 같은 NICE 연결 확인 수준 유지. 실결제·유료 AI 호출 테스트는 하지 않는다.

## 출시 예정 가격

옷 사진 1~5장은 각각 9,900 / 11,400 / 12,900 / 14,400 / 15,900원이다. 기본 9,900원에 추가 사진마다 1,500원이며 내 사진 1장, 착장 이미지 1장과 상세 코디 분석을 포함하는 계획이다. 빈 칸·사진 교체·원본 조합 미리보기는 계산하지 않는다.

`shared/ai-stylist-pricing.js`가 가격 원본이다. 화면, 공용 AI 카탈로그, NICE 심사 상품 허용 목록이 함께 사용한다. 서버는 브라우저 금액·MID·ReturnURL을 무시하고 선택한 `stylist_1`~`stylist_5` 가격을 서명한다.

## 90% 목표 마진 가정

실측 청구액이 아닌 계획 예산이다. 기존 AI 이미지 상품의 보수적 원가 예산을 기준으로 기본 500원(참조 2장, 생성 1장, 분석 1회와 예비비), 추가 옷마다 75원을 잡았다. 계획 환율은 1달러 1,500원, PG 수수료는 결제액의 3.5%, VAT는 10%다. 추가 75원은 약 0.05달러의 입력·분석 증가 예산이며 고정 공급자 요금이 아니다. 실제 모델·토큰·이미지 해상도·실제 수수료에 따라 변한다. 재시도는 예산을 별도 반영해야 하며 승인 전 실제 판매를 열지 않는다.

순매출 = 판매가 / 1.1
마진 = (순매출 - 판매가 × 0.035 - 변동원가예산) / 순매출

이 가정에서 모든 사진 수는 90% 이상이다. 고정 인건비·임대료·법인세를 차감한 순이익률을 의미하지 않는다. 이전 3,000~7,000원 정책을 대체한다.

참고한 공식 자료: https://developers.openai.com/api/docs/pricing 및 https://developers.openai.com/api/docs/guides/image-generation (2026-11-15 확인). 공식 자료는 토큰·이미지별 과금을 안내하며, 이 프로젝트의 500/75원 원가 예산을 보증하지 않는다.

## 현재 공개 범위

결제 방법 선택 버튼은 공용 NICE 모달에 업로드한 옷 수를 전달한다. 기존 카드·간편결제 연결 코드와 MID를 재사용하고 필수 안내 동의 후 연결 정보를 준비한다. 관리자 키는 기존 Pages Secret을 유지하며 코드에 넣지 않는다. 반환·승인·취소·상품 실행 경로는 계속 409로 차단한다. 사진은 브라우저에서만 처리하고 NICE에는 상품 번호·결제수단·약관 동의만 전달한다. 본 작업에서 실제 NICE 인증창, 실결제 또는 OpenAI 호출을 실행하지 않았다.

별도로 진행하던 Polar 실판매 경로는 사용자의 최신 범위에 따라 포함하지 않았다. Render API와 기존 결제 DB도 수정하지 않는다.

프런트엔드·Pages NICE 경로만 배포한다. 기존 Render API의 자동 재배포와 원장·스토리지 변경을 피하기 위해 출시 가격은 shared의 스토어프런트 확장 카탈로그에 둔다. 기존 node-api의 미사용 코디 가격 파일은 이번 NICE 연결의 가격 원본이 아니다.
