JSON을 붙여 넣고 **정리하기**를 눌렀는데 오류가 나온다면 **큰따옴표, 마지막 쉼표, 주석**부터 확인하세요. Windows 경로나 인용문을 넣었다면 **문자열 안의 역슬래시·따옴표·줄바꿈을 JSON 형식으로 표현했는지**도 확인해야 합니다. 매니툴 JSON 정리·검증기는 문법이 맞는 데이터를 정렬하며, 잘못된 문법을 자동으로 고치지는 않습니다. 이 글은 매니툴 운영팀이 현재 도구의 구현과 아래 예시를 확인해 작성했습니다.

## 먼저 원본을 따로 보관하세요

수정 전 내용을 텍스트 파일 등에 복사해 두세요. 도구에서 정리에 성공하면 입력창 내용이 정리된 결과로 바뀝니다. 오류가 나면 입력은 그대로 남고 아래에 오류 메시지가 표시됩니다.

설정 파일을 다룬다면 실제 비밀번호나 API 키 대신 가짜 값으로 예시를 만들어 확인하세요.

## 1. 키와 문자열을 큰따옴표로 감싸세요

다음은 자바스크립트 코드에서 볼 수 있는 형태지만, JSON으로는 올바르지 않습니다.

```text
{name: 'ManyTool'}
```

키인 `name`과 문자열 값인 `ManyTool` 모두 큰따옴표로 감싸면 됩니다.

```json
{"name": "ManyTool"}
```

문서 편집기에서 복사한 둥근 따옴표 `“ ”`도 JSON의 큰따옴표 `"`와 다릅니다. 숫자와 `true`, `false`, `null`은 원하는 자료형에 따라 그대로 쓰므로 모든 값을 무조건 따옴표로 감싸지는 마세요.

## 2. 마지막 항목 뒤의 쉼표를 지우세요

쉼표는 다음 항목과 구분할 때 사용합니다. 닫는 중괄호나 대괄호 바로 앞의 쉼표는 제거하세요.

잘못된 예:

```text
{"name": "ManyTool", "free": true,}
```

수정한 예:

```json
{"name": "ManyTool", "free": true}
```

배열도 `[1, 2, 3,]` 대신 `[1, 2, 3]`으로 씁니다.

## 3. 주석과 코드블록 표시를 빼세요

다른 곳에서 예시를 복사할 때 설명용 주석이나 코드블록의 시작·끝 표시까지 가져오면 오류가 날 수 있습니다. JSON 데이터 바깥의 마크다운 코드블록 표시와 `// 설명`, `/* 설명 */` 같은 주석을 제외하세요.

단, 문자열 안의 `https://manytool.net`에 있는 `//`는 주소의 일부입니다. `//`를 일괄 삭제하지 말고 실제 주석인지 먼저 확인하세요.

## 4. Windows 경로와 문자열 안의 따옴표를 확인하세요

아래 예시는 **도구 입력창에 직접 붙여 넣는 JSON 원문**입니다. 자바스크립트 코드나 명령줄 문자열 안에 JSON을 넣는 경우에는 바깥 언어의 규칙도 적용되므로 그대로 혼용하지 마세요.

Windows 경로를 그대로 넣은 다음 예시는 `\U`가 유효한 JSON 이스케이프가 아니어서 오류가 납니다.

```text
{"path":"C:\Users\sample"}
```

경로의 역슬래시 한 개를 JSON 원문에서는 두 개로 표현합니다.

```json
{"path":"C:\\Users\\sample"}
```

이때 읽힌 경로 값은 역슬래시가 한 개씩 들어 있는 `C:\Users\sample`입니다. **모든 역슬래시를 무조건 두 배로 바꾸지는 마세요.** 이미 올바르게 표현된 `\\`까지 늘리면 원래 값이 달라집니다. `{"path":"C:\temp"}`처럼 `\t`가 탭으로 해석되어 문법 검사를 통과하는 경우도 있으므로, 경로는 오류 유무뿐 아니라 의도한 값인지 확인하세요.

문자열 값 안에 큰따옴표가 필요할 때는 `\"`로 표현합니다.

잘못된 예:

```text
{"message":"그가 "확인"이라고 말했다"}
```

수정한 예:

```json
{"message":"그가 \"확인\"이라고 말했다"}
```

문자열 안의 줄바꿈도 Enter를 그대로 넣지 말고 `\n`으로 표현하세요. 다음 JSON의 `message` 값에는 첫째 줄과 둘째 줄 사이에 실제 줄바꿈이 들어갑니다.

```json
{"message":"첫째 줄\n둘째 줄"}
```

반대로 줄바꿈이 아니라 역슬래시와 글자 `n` 자체를 저장하려면 `\\n`으로 표현해야 합니다. 문자열 **밖에서** 항목 사이를 보기 좋게 나누는 줄바꿈은 허용됩니다.

## 수정한 결과를 확인하는 순서

1. [JSON 정리·검증기](/json-formatter)를 엽니다.
2. 위의 수정한 예시를 입력하고 **정리하기**를 누릅니다.
3. **올바른 JSON입니다.**라는 안내와 들여쓰기된 결과를 확인합니다.
4. 원본 데이터도 같은 방식으로 수정한 뒤 다시 검사합니다.
5. 줄바꿈 없는 결과가 필요하면 **한 줄로 줄이기**를 사용합니다.

현재 도구는 정리할 때 두 칸 들여쓰기를 사용합니다. 오류 문구와 위치 표현은 브라우저에 따라 다를 수 있습니다.

## 그래도 안 되거나, 별도 확인이 필요한 경우

중괄호·대괄호가 짝을 이루는지, 문자열 안의 큰따옴표가 올바르게 이스케이프되어 있는지도 확인하세요. 입력이 일반 JSON이 아닌 JSONC·JSON5·자바스크립트 객체라면 그 형식에 맞는 도구가 필요합니다.

**문법 검사 통과와 실제 서비스에서 사용할 수 있다는 것은 별개입니다.** 필수 항목 누락, 허용되지 않는 값, API별 데이터 구조는 이 도구가 검사하지 않습니다. 아주 큰 정수나 중복 키가 있는 데이터는 파싱 후 다시 저장하는 과정에서 값이 달라질 수 있으니 원본을 보관하고 결과를 비교하세요.

문법 검사는 통과했는데 긴 ID가 바뀌거나 값이 사라졌다면 [긴 숫자·중복 키의 원본 비교 방법과 대안](/community/json-values-after-format/)을 확인하세요. **한 줄로 줄이기**도 같은 파싱 과정을 거치므로 값을 보존하는 우회 방법은 아닙니다.

수정한 데이터는 [JSON 정리·검증기에서 다시 확인](/json-formatter)할 수 있습니다.
