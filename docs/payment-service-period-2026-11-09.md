# 유료 서비스 제공기간 안내 반영 기록

## 반영 범위

- 홈페이지와 이용약관에 일반 AI 생성·분석·파일 변환 상품이 결제 1건당 구매 화면에 표시된 결과를 제공하는 단건결제 상품임을 명시했다.
- 결제 확인 후 처리를 시작해 완료 결과를 제공하며 자동갱신되지 않는다는 안내를 관련 구매 화면에 추가했다.
- AI 펫 번역기를 결제일로부터 30일간 제공되는 1회 결제형 이용권으로 안내하고, 기존의 구독 표현을 30일 이용권 표현으로 정리했다.
- 정책 변경 전 결제 고객에게는 결제 당시 안내된 이용 범위와 기간을 적용한다고 명시했다.

## 펫 번역기 횟수 제한 확인

- 서버의 별도 토큰 경로에는 하루 5회 제한이 구현되어 있다.
- 결제 주문 및 결제 이메일 로그인 경로에는 같은 일일 횟수 제한이 구현되어 있지 않다.
- 이번 안내 변경에서는 기존 이용자의 권리를 소급 축소하거나 서버 제한을 새로 추가하지 않았다.
- 공통 화면에는 무제한이라고 표시하지 않고, 이용 경로별 횟수 제한은 해당 화면 안내를 따르도록 표시했다. 향후 모든 유료 경로에 동일 한도를 적용하려면 별도 상품정책 결정과 기존 고객 보호 방안이 필요하다.

## 결제사 설정 확인 한계

- 애플리케이션에는 정기결제 갱신·해지·다음 결제일 처리 로직이 없다.
- 실제 결제상품이 일회성 상품으로 설정됐는지는 Polar 관리자 화면에서 별도로 확인해야 한다. 이번 변경은 결제상품 설정이나 결제 연동을 변경하지 않았다.

## 검증

- `npm run build`: 성공, 5,510개 정적 페이지 생성.
- 기존 Vite의 브라우저용 `fs` 외부화 및 대형 청크 경고는 남아 있으나 이번 문구 변경과 관련된 빌드 오류는 없다.
