# Manytool 하이브리드 앱 경계

웹 도구의 UI·계산·AI API는 기존 웹 자산을 재사용하고, 필요한 기능만 Android가 담당합니다. 새 웹 도구가 이미 허용된 네이티브 기능만 사용하면 앱을 매번 다시 빌드할 필요는 없습니다. 다만 현재 개발판은 무료 도구 URL 허용 목록을 코드에 두므로 목록 확대는 앱 변경이며, 원격 카탈로그로 전환하려면 정책·보안 검증이 필요합니다.

## 실제 연결 코드

AndroidX WebKit `addWebMessageListener`를 사용합니다. 지원되는 WebView에서만 `https://manytool.net` origin, 허용된 도구 화면의 **메인 프레임**에 `ManytoolNative` 메시지 객체를 제공합니다. 구형 WebView에서 이를 지원하지 않으면 기능을 숨기며 취약한 `addJavascriptInterface` 대체를 하지 않습니다.

허용 명령은 세 개뿐입니다.

- `capabilities`: 지원 여부를 반환. 현재 saveText/shareText만 true, Play 결제·알림·인증 영상은 false.
- `saveText`: 64,000자 이하(직렬화 메시지 72,000자 제한)의 선택 내용을 네이티브 확인창에서 미리 보여주고 시스템 파일 저장창을 엽니다.
- `shareText`: 같은 확인 후 Android 공유 선택창을 엽니다. 실행 성공 응답은 UI를 열었다는 뜻이며 전송 완료가 아닙니다.

메시지/텍스트 크기 제한, 요청 ID 확인, 동시 확인창 제한, 입력 간격 제한, 페이지 변경·뒤로가기 이후 오래된 요청 중단을 적용합니다. 브리지는 쿠키·구매 토큰·비밀정보를 읽지 못하고 임의 URL 탐색, 임의 네이티브 메서드 호출, 결제를 허용하지 않습니다. 외부 SNS 페이지는 브리지 origin에 포함하지 않습니다.

웹 코드 `src/lib/manytool-native.ts`는 기능 확인과 선택 텍스트 저장/공유를 호출할 수 있습니다. 사진/음성 문서·번역 도구의 결과 화면에 지원되는 앱에서만 보이는 저장·공유 버튼을 연결했습니다. 웹 단독 실행의 기존 저장 동작은 유지합니다. 이 변경은 아직 원격 웹에 배포하지 않았으므로 현재 배포된 웹에는 새 버튼이 없습니다. 백그라운드 자동 공유·자동 업로드 용도가 아닙니다.

## 네이티브 결제

`PlayCreditBilling`과 `PlayCreditsPanel`은 별도 네이티브 모듈입니다. 인증된 앱 계정 연결 전에는 홈에서 실제 구매창을 열지 않습니다. 웹 JS 메시지로 세션이나 구매 토큰을 넘기지 않습니다. 구글 결제 가격은 Google ProductDetails, 적립·차감·검증은 공통 서버 원장으로 처리합니다. 자세한 미완료 범위는 mobile/android/PLAY_BILLING.md를 참조하세요.

## 미구현·미검증

알림/푸시 토큰, 실제 SNS 로그인·인증 다운로드, iOS, Play 실구매, WebView 실기기 저장·공유는 미완료입니다. 이 문서는 하이브리드 구조와 코드의 경계를 설명하며 스토어 출시 완료를 뜻하지 않습니다.
