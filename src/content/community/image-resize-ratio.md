사진의 원래 비율을 유지하려면 **비율 유지**를 선택한 상태에서 **가로 값**을 변경하고, 세로 값이 계산된 것을 확인한 뒤 저장하세요. **체크만 다시 켜는 것으로는 이미 입력한 세로 값이 복구되지 않습니다.** 매니툴 이미지 사이즈 변경기는 가로 입력을 기준으로 세로 값을 계산합니다. 이 글은 매니툴 운영팀이 현재 구현을 확인해 작성한 안내입니다.

## 시작 전에 확인할 조건

원본 사진을 별도로 보관하고, 제출처가 요구하는 가로·세로 픽셀과 파일 형식, 용량 제한을 확인하세요. 아래의 800픽셀은 사용 예시이며 모든 사이트의 제출 규격은 아닙니다. 이 도구는 사진을 자르지 않고 전체 이미지를 지정한 크기로 바꾸며, 결과를 PNG로 저장합니다.

## 따라 하는 순서

1. [이미지 사이즈 변경기](/image-resizer)를 열고 사진을 선택합니다.
2. 원본 가로·세로 값이 표시될 때까지 기다립니다.
3. **비율 유지**가 선택되어 있는지 확인합니다.
4. 가로에 `800`을 입력하고 세로가 자동으로 바뀌었는지 확인합니다.
5. 세로 값이 계산될 때까지 기다린 다음 **변경하고 다운로드**를 누릅니다. 결과는 `resized-image.png` 파일로 저장됩니다.
6. 내려받은 파일을 열어 가로·세로 픽셀과 얼굴·글씨의 모양을 확인합니다. 업로드할 때는 원본 대신 이 결과 파일을 선택합니다.

예를 들어 1600 × 1200 사진은 가로를 800으로 바꾸면 세로가 600이 됩니다. 비율을 유지한다고 해서 지정한 정사각형 규격에 자동으로 맞춰지는 것은 아닙니다.

## 비율 유지를 다시 켰는데도 세로가 어색하다면

체크를 끈 상태에서 세로를 바꿨거나, 체크가 켜져 있어도 세로를 직접 수정했다면 가로·세로 비율이 달라질 수 있습니다. 체크 표시가 다운로드 순간에 비율을 다시 맞춰 주지는 않습니다.

1. **비율 유지**를 켭니다.
2. 가로에 원하는 값을 다시 입력합니다. 이미 `800`이라면 값을 지우고 `800`을 다시 입력하세요.
3. 원본이 1600 × 1200이라면 세로가 `600`으로 바뀌는지 확인합니다. 자동 계산은 현재 입력한 세로가 아니라 선택한 원본 사진의 비율을 기준으로 합니다.
4. 세로를 따로 고치지 않고 **변경하고 다운로드**를 눌러 새 파일을 받습니다.

세로 계산은 `가로 × 원본 세로 ÷ 원본 가로`를 반올림한 값입니다. 예를 들어 1200 × 1600인 세로 사진은 가로 800일 때 세로가 1067이 됩니다. 정수 픽셀로 반올림되므로 계산 결과에 소수점이 있다면 아주 작은 비율 차이는 생길 수 있습니다.

## 안 되는 경우와 주의할 점

- 현재는 가로를 바꿀 때 세로가 계산됩니다. 세로만 입력하면 가로가 자동으로 바뀌지 않으니 두 값을 확인하세요.
- 가로·세로는 0보다 큰 정수로 입력하세요. 너무 큰 이미지 크기는 기기의 메모리 한계로 처리되지 않을 수 있습니다.
- 브라우저가 읽지 못하는 이미지 형식이라면 JPG나 PNG 원본으로 다시 시도하세요.
- 작은 사진을 크게 늘려도 원본에 없던 디테일이 복원되지는 않습니다.
- 제출처가 가로·세로를 모두 지정했는데 원본 비율과 다르면, 두 값을 억지로 입력할 경우 사진이 찌그러집니다. 제출처가 허용하는 범위에서 자르기 편집기로 비율을 먼저 맞추거나 적합한 원본을 준비하세요. 이 도구에는 자르기나 여백 추가 기능이 없습니다.

## 픽셀을 줄였는데 파일 용량은 왜 클까요?

가로·세로 픽셀과 파일 용량은 서로 다른 기준입니다. 이 도구는 PNG로 저장하므로 원래 JPG보다 용량이 커질 수도 있습니다. 업로드 제한이 KB나 MB라면 [사진 용량을 줄이는 방법](/community/image-file-size/)을 확인하세요.
