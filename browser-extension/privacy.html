데이터와 권한 안내

사용자가 실행한 내용만

방문 기록 전체, 로그인 쿠키, 비밀번호를 읽지 않습니다. 모든 사이트에서 상시 실행되는 스크립트도 없습니다. 버튼·우클릭·단축키를 실행하면 현재 탭에서 선택한 글, 주소 또는 보이는 영역을 처리합니다. 입력란은 자동으로 읽지 않습니다. 현재 페이지 드래그 메뉴를 켜면 선택 글을 페이지 안에서 감지하고, 메뉴를 클릭할 때만 확장의 로컬 검토 화면으로 전달합니다. 새 페이지에서 자동으로 켜지지 않으며 × 버튼으로 끌 수 있습니다. 이미지 우클릭은 이미 표시된 이미지를 로컬로 읽으며 원본 서비스에 쿠키를 전달하는 별도 요청을 하지 않습니다.

캡처와 글의 보관

캡처는 기기에서 선택 영역만 잘라 검토 탭으로 전달합니다. 전달 대기 자료는 확장의 세션 저장소에 최대 10분 보관되며 다음 정리 주기(약 1분, 브라우저 절전 시 지연 가능)에 삭제됩니다. 검토 탭이 읽으면 즉시 저장소에서 삭제하고 화면 메모리에만 둡니다. 새로고침·닫기 시 내용은 사라집니다. 직접 저장한 파일·클립보드·브라우저 검색 기록은 사용자가 관리합니다.

다른 사이트에 전달하기

동의 후 ‘매니툴로 전달하기’를 누를 때만 선택 내용이 manytool.net의 도구 입력란으로 전달됩니다. URL이나 검색 파라미터에 내용을 싣지 않습니다. 해당 페이지 스크립트는 내용에 접근할 수 있습니다. 현재 OCR·번역 도구는 기기에서 처리하며 모델 파일은 외부 배포처에서 다운로드합니다. Google 검색은 별도 확인 후 선택 글을 Google에 보냅니다.

권한

  • activeTab·scripting: 실행한 탭에서 선택 글 읽기, 영역 선택, 캡처.
  • contextMenus: 선택 글과 주소의 우클릭 메뉴.
  • storage·alarms: 일회성 검토 자료 전달과 만료 정리.
  • 선택 권한 https://manytool.net/*: 동의 후 새 도구 탭의 입력란 연결. 브라우저 설정에서 철회할 수 있습니다.

아직 제공하지 않는 것

로그인 세션 추출, 비공개/스토리 영상 저장, 자동 유료 AI 호출, 크레딧 차감, 원격 브라우저는 이 버전에 없습니다. 확장 스토어에 등록되지 않은 개발 미리보기입니다. 게시 전 실제 브라우저 검증과 최종 개인정보처리방침 검토가 필요합니다.
