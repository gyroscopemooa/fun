여러 파일을 `여행사진-001.jpg`, `여행사진-002.jpg`처럼 만들려면 파일을 한꺼번에 선택하고 접두사를 입력한 뒤 **이름 바꿔 다운로드**를 누르세요. 매니툴 파일명 일괄 변경기는 원본 파일을 고치지 않고, 새 이름이 붙은 사본의 다운로드를 하나씩 시작합니다. 이 글은 매니툴 운영팀이 현재 구현을 확인해 작성한 안내입니다.

## 시작 전에 확인할 조건

- 이름을 바꿔도 원본은 그대로 남습니다. 결과는 브라우저 다운로드 폴더에 새 파일로 저장되므로 필요 없는 원본은 직접 정리해야 합니다.
- 번호는 선택된 파일 목록의 순서대로 `001`부터 붙습니다. 정렬 기능은 없으므로, 날짜순이나 이름순으로 번호를 받으려면 파일 선택 창에서 원하는 순서가 되도록 선택하세요.
- 접두사를 비워 두면 `file`이 사용됩니다.

## 따라 하는 순서

1. [파일명 일괄 변경기](/bulk-file-renamer)를 엽니다.
2. 파일 선택 칸에서 이름을 바꿀 파일을 모두 선택합니다.
3. 접두사 칸에 `여행사진`처럼 앞에 붙일 이름을 입력합니다.
4. **이름 바꿔 다운로드**를 누릅니다. 선택한 개수만큼 다운로드가 시작되었다는 문구가 표시됩니다.
5. 다운로드 폴더에서 파일 개수와 번호 순서, 확장자를 확인합니다.

예를 들어 `a.jpg`, `b.jpg`, `c.png`를 이 순서로 선택하고 접두사를 `여행사진`으로 입력하면 `여행사진-001.jpg`, `여행사진-002.jpg`, `여행사진-003.png`가 만들어집니다.

## 확장자와 번호가 예상과 다를 때

- 확장자는 마지막 점 뒤의 글자만 유지합니다. `backup.tar.gz`는 `.gz`만 남으므로 이런 파일은 결과 이름을 확인하세요.
- 확장자가 없는 파일에는 확장자가 붙지 않습니다.
- 번호는 3자리로 채워집니다. 1000번째 파일부터는 4자리가 됩니다.
- 이 도구는 접두사와 번호만 붙입니다. 기존 이름 일부를 찾아 바꾸거나 뒤에 날짜를 붙이는 기능은 없습니다.

## 일부 파일만 저장된 것 같을 때

이 도구는 ZIP으로 묶지 않고 파일을 하나씩 내려받습니다. 브라우저가 여러 파일 다운로드를 한 번에 허용할지 묻거나 차단하는 경우가 있으므로, 주소 표시줄이나 다운로드 알림에서 허용 여부를 확인하세요. 허용한 뒤에는 이미 받은 파일과 이름이 겹치지 않도록 다운로드 폴더를 비우거나, 작은 묶음으로 나누어 다시 시도하세요. 같은 이름의 파일이 이미 있으면 브라우저가 이름 뒤에 `(1)` 같은 표시를 붙일 수 있습니다.

파일 수가 아주 많거나 이름 규칙이 복잡하다면 여러 번에 나누어 처리하고, 중요한 파일은 작업 전에 별도 폴더에 백업해 두세요.

## 관련 안내

- 사진 파일의 가로·세로 크기를 먼저 맞춰야 한다면 [사진 크기 조절하기 안내](/community/image-resize-ratio/)를 확인하세요.
- 업로드 용량 제한 때문에 사진을 줄여야 한다면 [사진 용량 제한 확인 방법](/community/image-file-size/)을 확인하세요.

조건을 확인했다면 [파일명 일괄 변경기에서 번호 붙이기](/bulk-file-renamer)로 진행하세요.
