로그인 후 주소로 다운로드

실브라우저 연결 실험입니다.
실제 인스타그램·X와 연결되지 않습니다. 비밀번호나 쿠키를 입력하지 마세요. 다운로드 결과는 내장된 1초 테스트 영상이며 외부 사이트 영상이 아닙니다.

브라우저 시작 → 아래 화면 안의 모의 로그인 클릭 → 테스트 주소 입력 → 결과 저장

서버 브라우저 화면 (클릭·터치 지원, 약 1초마다 갱신)

지원 예시: https://media.example.test/videos/demo-video

시작 전입니다. 세션은 최대 5분 후 자동 삭제됩니다.

별도 Chromium 프로세스 화면을 전송합니다. 내장된 모의 사이트만 열 수 있으며 실제 서비스 로그인은 지원하지 않습니다. 운영용 컨테이너 격리와 외부 통신 방화벽은 아직 없습니다. 다른 탭이나 앱의 로그인은 자동 공유되지 않습니다.
