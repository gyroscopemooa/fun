# 공개 1번 완성 배선 · 추가 검증 기록

기준일: 2026-10-27. 기존 자기유지 P0 이후, 사용자가 요청한 공개 1번 완성 예제로 범위를 확장했다.

## 공식 자료와 구현 범위

[큐넷 공개문제 게시물](https://www.q-net.or.kr/cst006.do?artlSeq=5208377&brdId=Q006&gSite=Q&id=cst00602&page=1)의 `전기기능사 공개문제, 2025-08-04.zip`에서 001번을 확인했다. 6쪽 기구 배치, 7쪽 시퀀스, 8쪽 동작 사항, 9쪽 기기 핀 배열을 대조했다. 공식 PDF·이미지는 사이트에 재배포하지 않는다.

26개 기기/외부 입력과 전선 101개로 작성한 자체 결선 예제다. 상단 TB5·하단 TB6는 각각 10P 두 개이고, 같은 극의 A/B 나사만 내부 연결된다. 12P 및 8P 소켓의 핀 배치를 구현했다. TB5/TB6 각 극의 기능 배정은 예제에서 정한 배정이며 공식 정답 번호표라고 주장하지 않는다. SS의 M1/M2/A1/A2 및 PB의 13/14/21/22는 도구의 논리 접점 식별자다.

- MC1/MC2: 코일 6–12, 주접점 1–7/2–8/3–9, NO 4–10, NC 5–11.
- X: 코일 2–7, NO 1–3/8–6, NC 1–4/8–5.
- T: 코일 2–7, 순간 NO 1–3, 시간 NO 8–6 및 NC 8–5.
- FR: 전원 2–7, COM 8, 교대 접점 5/6.
- EOCR: 전원 6–12, 공통 10–11, 정상 4–10, 트립 5–11.
- FLS: 전원 5–6, COM 4/NO 3/NC 2, E1=7/E2=8/E3=1.

## 동작과 사용법

페이지를 열면 완성 배선을 표시한다. 실행 → SS 수동 M → PB1을 누르면 MC1/RL 및 T가 동작하고, PB1을 놓아도 T의 순간 접점으로 유지한다. 3초 뒤 T의 시간 접점으로 MC2/GL을 켠다. PB0으로 정지한다. T의 설정 시간은 기기 선택 후 변경할 수 있다.

SS 자동 A에서 수위 상한 입력이 FLS의 실제 외부 전극 결선을 통해 감지되면 X/MC1/RL을 켠다. 중간 수위에서는 유지하고 하한에서는 해제한다. X의 NC 접점은 자동 중 타이머 회로를 차단한다.

EOCR 시험 트립은 정상 접점을 열고 FR 회로를 공급한다. FR이 0.5초마다 BZ/YL을 교대로 켠다. RESET으로 초기 상태로 복귀한다. 부저 소리는 사용자가 켠 경우에만 Web Audio로 재생하며 BZ의 계산 상태와 연동된다.

시작 단자 클릭 → 빈 곳 클릭으로 꺾기 → 끝 단자 클릭으로 결선한다. Esc 취소, Backspace 마지막 점 취소, 선택한 꺾임점 드래그/방향키 이동, Undo/Redo를 지원한다. 피복 색과 꺾임점은 JSON에 저장되며 계산 결과를 바꾸지 않는다. 피복 색은 통전 시 유지되고 통전 경로는 초록 테두리로 구별한다.

`어떻게 연결했나요?`의 결선표 행을 클릭하면 해당 전선을 강조한다. `전체 보기`로 전체 작업판을 볼 수 있고, 줌으로 단자를 확대한다. 빈 과제/완성 배선 불러오기 및 기본 자기유지 과제도 제공한다.

## 전기 계산의 범위

- 균형 3상 220V 선간 RMS 페이저를 고정 전원으로 두고, 실제 전선/내부 접점 그래프를 축약해 노드 전압을 계산한다. 코일·램프·부저는 정적 저항 부하다. 정격 전압의 80%를 동작 문턱으로 사용한다.
- 타이머/FR 시간은 입력 가상 시간으로만 진행하고, 실제 코일 전압이 없으면 진행하지 않는다. FLS는 전원과 E1/E2/E3 도통을 모두 요구한다.
- 서로 다른 상/상–PE 직접 접속, 퓨즈 과전류/우회, 잘못된 주회로 상 배선, PE 귀환 전류, 단선·저전압 및 발진을 검사한다. 단락/퓨즈 과전류는 교육용 전체 전원 인터록으로 래치한다.
- M1/M2는 실제 회전/토크 모델이 아니라 TB2/TB3에 L1/L2/L3가 올바르게 도달했는지 계산한 출력 상태다. 전동기 부하 전류는 계산하지 않는다. 무부하 주회로를 가짜 전류 흐름으로 표시하지 않는다.
- EOCR의 시험 트립은 외부 과부하 신호 주입이다. 전동기 열/과부하 곡선이나 실제 EOCR 제품 알고리즘은 구현하지 않았다. 별도로 저항 부하 과전류에 따른 퓨즈 차단은 계산한다.
- 배관 가공, 실제 접지/절연 저항, 접촉 저항, AC 과도현상, 제품별 흡입/탈락 특성, 전체 실기 외관/전선 굵기/색상 채점은 미구현이다. 공인 시험 채점기나 실물 시공 안전 검증기가 아니다.
